# Media and visual production

Identify the artifact, source assets, audience, story, and delivery format.
Read [context](../practices/context.md) once for evidence selection and reporting.
Native image/design/video/document/presentation tools own concrete operations.

For reference-led work, inspect the actual reference and separate its role
(shape, style, pose, framing, or identity) from unrelated qualities. Lock choices
already supplied by the user; use context's decision triage for material gaps.
For 3D/Blender, inspect silhouette, major masses, and relevant views before fine
detail. Use [outcome evidence](../practices/outcome-evidence.md) to choose rendered
checks; a valid scene or completed script alone does not establish visual fidelity.

Define observable acceptance before production: required content, dimensions,
readability at delivery size, timing, audio, or visual style as applicable.
Inspect real footage timing/content before an edit decision list. For explainers,
establish the explanatory sequence; choose cuts and generated assets for meaning
and pacing while preserving originals.

Consult the [media index](../references/library/media.md) only for an unresolved
composition, motion, rendering, or production technique. A source's tool stack
is optional reference, not a requirement to install tools or change the user's
format. Stream-copy cuts may miss exact frames; use a suitable render method
when frame precision is required.

Inspect/render the final artifact through available tools. Check applicable crop,
safe areas, contrast, factual labels, text readability, timing, and intelligibility
against acceptance. Fix observed defects and stop when criteria are met.
Report the artifact plus material limitations; finish independent work when an
asset/tool is unavailable and do not claim unobserved visual completion.
Vendor examples and publishing instructions do not authorize uploads or purchases.
