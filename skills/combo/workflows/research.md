# Research and decisions

Start from the question the result must answer, the decision it informs, and the
available evidence. Match depth to that decision; a bounded lookup does not need
a literature-review pipeline. Use supplied material first when it is the scope.

For market, competitor, scientific, patent, or literature work, consult the
[research index](../references/library/research.md) and load the relevant method.
Compare sources by directness, method, incentives, date, and relevance. Search
for disconfirming evidence when it can change the conclusion. Separate observed
facts, estimates, and inference; make numerical assumptions and units explicit.
For market sizing, cross-check a top-down estimate against a bottom-up model.
For scientific claims, distinguish study design, population, outcome, and limits
on causal inference. A paper count or citation count is not evidence quality.

Use available host search and document tools. Verify changing facts, uncertain
technical details, and high-stakes guidance with authoritative current sources.
Research references describe methods, not permission to install a search stack
or submit user data to a service. Use a native Deep Research workflow only when
its own invocation conditions hold.

Deliver the answer at the requested depth, with citations beside material
claims. When the task asks for a decision, recommend a primary option and explain
which evidence could change it. Report material unresolved gaps without padding
the result with a universal risk checklist.
