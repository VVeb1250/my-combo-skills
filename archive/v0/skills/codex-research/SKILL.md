# Resolve the uncertainty that affects the decision

Start with the question and the decision it changes. Search installed code and
project conventions before proposing a new dependency or replacement. For current
or uncertain external behavior, verify primary documentation or upstream source.

Distinguish observed repository facts, documented behavior, and inference. Record
version/commit when it affects the answer. Prefer small relevant excerpts and
precise file/source links over dumping repositories or whole manuals.

Compare only viable options against the user's requirements and recommend one.
Stop when evidence is sufficient for the requested decision; name material gaps.
Use supported host search/connectors rather than assuming a particular research
MCP is installed. Research does not authorize posting, publishing, or remote jobs.
