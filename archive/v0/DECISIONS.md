# Curation decisions

Owner approved immediate Codex-only setup with baseline and rollback, superseding
the handoff's 2-3 day budget-only trial. Claude and ChatGPT web are deferred.
This is an immediate automatic-discovery profile, not a completed Arm A/B experiment.

The four upstream repositories were fetched directly from GitHub. Commit pins are
in `sources.lock.json`; the original installed corpus is retained for comparison.
Upstream packages are source material, not authorization to run their installers,
hooks, remote jobs, memory systems, or workflow routers.

Changes deliberately made during distillation:

- Karpathy: material ambiguity is surfaced; routine correct choices do not force a
  confirmation. Surgical scope follows a demonstrated root cause across files.
- Ponytail: the shortest correct maintainable solution preserves justified design.
  Removed persistent persona, arbitrary output length, line-count targets, unsafe
  example substitutions, and replacing explicitly requested behavior with a shortcut.
- Matt: retain behavior tests at public seams, vertical slices, real adapters,
  standards/spec review lenses. Remove mandatory seam confirmation, tracker bootstrap,
  exhaustive user-story output, and automatic parallel review fanout. Keep review
  findings ranked by material consequence. Existing authorization governs publishing.
- ECC: retain security/build/E2E/language expertise and selected technology references.
  Remove blanket security checklists for unrelated edits, mandatory dependencies,
  fixed test coverage targets, retries without diagnosis, and extra workflow owners.

The 17 direct skills are automatically discoverable. Their bodies are short;
six contain optional, pinned upstream examples in references. A retained library
catalog keeps uncommon specialists accessible without advertising hundreds of
overlapping descriptions. Existing distinct native plugins and utility skills stay.

Every corpus file has a manifest decision. Mechanical parsing and name collisions
were checked across the entire corpus. Full-body semantic review is limited to
the core/selected specialists and the explicitly reported audit subset. LIBRARY
does not mean every line of a rare-domain reference has been semantically approved.

Metrics: real app-server discovery before/after, exact description characters,
installer safety checks, and bounded behavioral smoke checks are distinct evidence.
None proves lower intervention rate or reliable triggering on every model.
The 15-real-task outcome log and multi-model benchmarks remain future measurement.
