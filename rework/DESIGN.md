## Contract

Improve correct autonomous outcomes, judgment, creative exploration, understanding, verification and recoverability at minimum total cost. Single main agent by default; native host, Git, tests, existing documentation and tools form the harness. Human owns consequential product choices and external/shared effects. Use standing local authority only if actually granted; preserve others' work. No memory database, runtime orchestrator, custom Git engine or knowledge compiler dependency.

- Compose methods at the action that needs them, not a primary task route. Source-grounded fresh authoring, preserve proven mechanisms not old packaging. Six implicit clusters and five explicit entries are a candidate, not an established optimum.
- Ground new behavior in accepted independent expectations; choose keep/reuse/remove/repair/refactor/rework by causal evidence; verify real outcomes and affected callers. Preserve valid contracts, not faulty premises.
- Maintain a compact read-write wiki with or without `.combo/`: cold-start navigation, domain mental models, canonical ownership, current intent vs reality vs evidence, semantic deltas before/during/after changes. No routine diary or generated index. Preserve old knowledge and link ownership during migration.
- Git-backed work: baseline and ownership; authorized local meaningful checkpoints throughout; coherent code/tests/docs; isolated experiments; selective integration and safe recovery. No implicit push, shared changes, or destructive action on uncertain ownership.
- Fresh session, changed focus, interruption and compaction: recover relevant intent, Git state, evidence, pending action, permissions. Durable transition when needed before risking loss. Hard stop forbids further mutation. Native hooks may reinforce recovery but must not auto-write/commit or claim semantic enforcement.
- General-purpose research, learning, production, business and productivity remain supported. Preserve domain capability, not the legacy specialist inventory. Use a small problem-first technique shelf for non-obvious decisions, failure modes and evidence; native reasoning for basics and version-matched primary documentation for volatile facts. Preserve source provenance, host model preferences, conditional delegation, transactional installer and rollback. Retire compiler and mandatory routing only after tested migration.

## Behavior and interface boundary

Combo owns judgment, not the implementation of every interaction surface. Use native, project, external or agent-authored interfaces independently; no required third-party tool, interface abstraction, registry, universal compressor, logging schema or shortcut subsystem. Improve the total cost of correct work through semantic economy, direct observation and validated shortcuts. Choose reuse, discovery, synthesis or composition by actual need, fidelity, risk, setup and lifecycle cost, not a fixed search/build order. Avoid speculative or out-of-scope environment changes. Preserve useful project-specific improvements in existing canonical knowledge; retire them when invalid or uneconomic. User outcomes take priority over optimizing the environment.

## Evidence required

Independent acceptance and authority first; then comprehension, documentation update recall/precision, checkpoint quality and recovery, lifecycle cost. Compare native/current/one-skill/cluster/atomic candidates under matched settings. Test with and without wiki and hooks, multi-session read-write-read, real interruptions/compaction, dirty Git, negative controls, noncoding. Static checks do not prove behavior. See [eval protocol](evals/README.md).
