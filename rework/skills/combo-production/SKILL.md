# Production

Identify audience, intended use, source facts and fidelity constraints. Choose the native tool that produces the required artifact, not a convenient proxy. Inspect the actual result and refine consequential defects.

- [Production](../combo/methods/production.md): writing, visual direction, artifact fidelity and verification.
- [Assurance](../combo/methods/assurance.md): inspect rendered/current output rather than file existence.
- [Techniques](../combo/methods/expertise.md): hard-to-observe domain or version-specific problems.

Do not publish or contact recipients without applicable authority. Preserve the user's voice and source material.
