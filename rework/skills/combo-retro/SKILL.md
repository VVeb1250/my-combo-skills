# Retro

Use [improvement](../combo/methods/improvement.md). Inspect the selected session and actual artifacts within authorization. Distinguish missing capability, discovery, activation, execution, environment and verification failures. Choose the smallest effective intervention and test against the original failure; do not install changes or access unrelated transcripts without authority.
