# Diagnose

Get a discriminating feedback signal before speculative repairs. Trace the actual failing path and compare plausible causes; test a supported architectural contradiction immediately.

- [Diagnosis](../combo/methods/diagnosis.md): reproduction, instrumentation, non-determinism and causal probes.
- [Design](../combo/methods/design.md): repair vs refactor vs rework at the responsible boundary.
- [Git techniques](../combo/methods/git.md): known-good/bad revisions, bisect, history and safe recovery.
- [Techniques](../combo/methods/expertise.md): hidden resource, concurrency, data or domain-specific causes.
- [Experiment](../combo/methods/experiment.md): uncertain mechanisms and performance comparisons.

Correct false project understanding as it is established. Diagnosis-only requests stop before edits.
