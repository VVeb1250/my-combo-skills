# Techniques by problem

Choose the observation or decision you cannot yet make reliably. These are targeted methods, not language lessons. Read one relevant page, then return to the project evidence.

| Signal | Technique |
|---|---|
| Stale state, conflicting writers, races, deadlocks, cancellation or resource leaks | [State and lifetime](state-lifetime.md) |
| Slow data access, unexpected row counts, query-plan changes | [Query diagnosis](query-diagnosis.md) |
| Schema, API or data changes with independently deployed callers or persistent state | [Contract migration](contract-migration.md) |
| Geometry, rigs, motion, contact or spatial output looks plausible but may be wrong | [Spatial verification](spatial-verification.md) |
| Model/agent comparisons, noisy benchmarks, leakage or misleading metrics | [Evaluation validity](evaluation-validity.md) |

If none fits, use the relevant shared method and version-matched documentation, not a generic specialist tutorial. Add a technique only for a consequential gap with a distinct decision or check. See [authoring](../methods/improvement.md).
