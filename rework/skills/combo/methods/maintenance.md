# Maintenance and migration

Identify the actual Combo checkout, host/version, installed ownership receipt and target profile. Inspect current source manifests, host adapter, installer and rollback interface. Preserve other instructions, models, credentials, native permissions, memory settings and unrelated configuration. Plan and preview managed paths; do not manually delete uncertain files, globally disable other plugins or overwrite user settings to make a candidate work.

For changes, stage source in an isolated owned branch; preserve old source and license provenance. Test install/upgrade/rollback in disposable fake homes first, compare unrelated files/config, verify actual native discovery and invocation semantics for each host. Preserve old project wiki records and evidence while removing runtime dependence on the compiler; never delete existing metadata or generated artifacts merely because the new design does not need them. Only install on the user's live environment when requested and permitted. Host hooks are optional, narrowly scoped, version-tested context cues; no auto mutation. Do not merge, push, publish or change permissions without authorization. Report receipt, evidence and actual installed state; a candidate source tree is not an installed capability.
