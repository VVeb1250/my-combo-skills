# Learning

Start from the learner’s current understanding and desired capability. Teach the mechanism with a concrete example; connect it to the larger model and test transfer rather than recall alone.

Use [learning](../combo/methods/learning.md) for conceptual sequencing, guided practice and misconception checks. For project-based lessons, inspect the relevant existing project evidence rather than inventing behavior. Do not turn a lesson into implementation without authorization.
