# Maintain

Use [maintenance](../combo/methods/maintenance.md). Discover the actual installed version, host and repository before any mutation. Use the established transactional installer and verify/rollback facilities, not manual destructive copies. This candidate must not be installed until its migration and host discovery tests pass.
